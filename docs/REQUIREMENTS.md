# Сопоставление с HW55

Источник требований — комментарии технического задания в приложенном src/main.js и ожидания src/__test__/*.test.js. Отдельного PDF с заданием в этой папке нет; приложенная лекция используется как контекст, но не заменяет спецификацию исходного проекта.

Реализация исходного nodejs-hw02-tests: асинхронная запись, чтение и удаление файлов через fs/promises.

writeFileAsync возвращает undefined при успехе и объект Error при ошибке, логируя результат. readFileAsync возвращает строку (включая пустую) при успехе и null при ошибке. deleteFileAsync возвращает undefined при успехе и Error при ошибке. ENOENT у чтения/удаления имеет отдельное сообщение. Контракт возврата write/read согласован с приложенными тестами, а не заменён выбрасыванием исключений.

Импорт fs/promises сохранён именно в такой форме: исходные тесты мокируют этот идентификатор. Формулировки сообщений на украинском сохранены из технического задания. Демо и нативные тесты используют временные директории с очисткой в finally; пользовательские файлы они не изменяют. Параллельные операции с разными файлами поддерживаются; конкурентные записи в один файл вызывающая сторона должна упорядочивать.


Дополнительно подготовлены нативные тесты, безопасная CLI-демонстрация, статическая страница и GitHub Actions. Проверка исходных Vitest-тестов требует установки зависимостей; она не заявляется выполненной в офлайн-среде.
